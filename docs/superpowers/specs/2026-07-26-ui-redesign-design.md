## 背景与目标

### 当前问题

PDFOCR 当前 UI 基于 PyQt6 + qfluentwidgets，采用固定三栏布局（文件列表 15% + PDF 预览 63% + 字段/结果 22%）。经过代码分析，存在以下关键问题：

1. **硬编码尺寸过多** — 左栏 min=220/max=400、右栏 min=320/max=450，在小屏幕上显示不全
2. **Splitter 初始尺寸计算问题** — 窗口布局完成前获取 `self.width()`，导致初始比例不准确
3. **嵌套 Splitter 复杂** — 外层 + 内层 middle_splitter，手动模式下版面可视化隐藏但 splitter 仍占空间
4. **样式碎片化** — 10+ 文件中分散的 `setStyleSheet()`，无统一主题管理
5. **暗色模式不协调** — 自定义颜色（如 `#fafafa`）在暗色主题下突兀
6. **工具栏间距不一致** — 多处 `addSpacing(4/6/8)` 无统一标准
7. **空状态组件重复** — 三个面板各自实现相似的空状态

### 设计目标

1. **响应式布局** — 自适应屏幕尺寸，支持面板折叠/展开
2. **统一设计系统** — 提取 ThemeManager，集中管理颜色、字体、间距
3. **提升信息密度** — 紧凑工具栏、动态快捷键提示、统一空状态
4. **优化交互体验** — 动画过渡、键盘工作流、即时反馈
5. **暗色模式完美适配** — 所有颜色通过主题系统动态映射

---

## 设计原则

1. **内容优先** — 主工作区占据最大空间，次要面板可折叠
2. **一致性** — 统一的间距、圆角、颜色系统
3. **效率** — 减少操作步骤，支持纯键盘工作流
4. **反馈** — 每个操作都有即时视觉反馈
5. **容错** — 错误状态提供明确的修复指引

## 布局架构

### 整体结构

```
FluentWindow
├── 顶部工具栏 (CompactToolbar)          [高度: 36px, 固定]
│   ├── 主要操作组（图标按钮）
│   ├── 模板操作组
│   └── 引擎状态 + 设置
│
├── 主内容区 (MainContent)
│   └── QHBoxLayout
│       ├── 左侧面板 (CollapsiblePanel)   [宽度: 240px, 可折叠至 48px]
│       │   ├── 文件列表 (FileListPanel)
│       │   └── 批量进度指示
│       │
│       ├── 中央工作区 (DynamicWorkspace)  [占据剩余空间]
│       │   ├── PDF 预览 (PdfCanvas)
│       │   ├── 图像预处理工具栏 (可折叠)
│       │   └── 版面可视化 (VLM 模式, 浮动)
│       │
│       └── 右侧面板 (SlidablePanel)      [宽度: 320px, 可收起]
│           ├── 字段配置 (FieldPanel)
│           └── 解析结果 (ResultPanel)
│
└── 底部状态栏 (StatusBar)                [高度: 24px, 固定]
    └── 动态状态 + 快捷键提示
```

### 面板行为

#### 左侧面板（文件列表）

- **展开状态**: 宽度 240px，显示完整文件列表
- **折叠状态**: 宽度 48px，仅显示图标栏 + 文件数量徽标
- **切换方式**: 点击面板边缘的折叠按钮，或快捷键 `Ctrl+Shift+L`
- **悬停展开**: 折叠状态下悬停 500ms 临时展开，移开 1s 后收回

#### 右侧面板（字段/结果）

- **手动模式**: 识别字段时自动滑入，完成后可手动收起
- **自动/VLM 模式**: 显示为可收起的浮动面板
- **切换方式**: 点击面板边缘按钮，或快捷键 `Ctrl+Shift+R`
- **宽度调整**: 支持拖拽调整（最小 280px，最大 480px）

#### 中央工作区

- **手动模式**: PDF 预览占据全部宽度
- **VLM 模式**: PDF 预览 60% + 版面可视化 40% 并排显示
- **模式切换动画**: 淡入淡出 200ms

## 组件详细设计

### 1. ThemeManager（主题管理器）

**职责**: 集中管理所有视觉常量，支持明/暗色切换

**接口设计**:

```python
class ThemeManager:
    """主题管理器 - 集中管理所有视觉常量"""

    # 配色映射
    COLORS = {
        'light': { ... },
        'dark': { ... }
    }

    # 字体层级
    FONTS = { ... }

    # 间距
    SPACING = { ... }

    # 圆角
    RADIUS = { ... }

    @classmethod
    def get_color(cls, role: str) -> str:
        """获取当前主题下的颜色值"""
        ...

    @classmethod
    def get_font(cls, level: str) -> QFont:
        """获取指定层级的字体"""
        ...

    @classmethod
    def get_spacing(cls, name: str) -> int:
        """获取间距值"""
        ...

    @classmethod
    def get_radius(cls, name: str) -> int:
        """获取圆角值"""
        ...

    @classmethod
    def apply_stylesheet(cls, widget: QWidget, styles: dict):
        """应用样式到控件"""
        ...
```

**实现位置**: `app/ui/theme_manager.py`

### 2. CompactToolbar（紧凑工具栏）

**职责**: 顶部操作栏，图标化设计，节省空间

**布局**:

```
┌─────────────────────────────────────────────────────────────┐
│ ⬆️  🔍  ▶️  │  💾  📂  │  ●GGUF  ▼  │  ⚙️  │  ?  │        │
│ 上传 试识 批量  │ 保存 加载  │ 引擎状态   │ 设置 │ 帮助 │  [窗口控制] │
│ Ctrl+O Ctrl+T  │ Ctrl+S     │            │      │      │        │
└─────────────────────────────────────────────────────────────┘
```

**组件**:

| 图标 | 操作 | 快捷键 | 说明 |
|------|------|--------|------|
| ⬆️ | 上传 PDF | Ctrl+O | 文件选择对话框 |
| 🔍 | 试识别 | Ctrl+T | 单页识别测试 |
| ▶️ | 批量识别 | Ctrl+Enter | 批量处理 |
| 💾 | 保存模板 | Ctrl+S | 保存当前模板 |
| 📂 | 加载模板 | - | 加载已有模板 |
| ●GGUF | 引擎切换 | - | 下拉选择引擎 |
| ⚙️ | 设置 | - | 打开设置对话框 |
| ? | 帮助 | F1 | 快捷键帮助 |

**引擎状态指示**:

- ● 绿色脉冲 = GPU 就绪且可用
- ● 黄色 = GPU 初始化中
- ● 红色 = GPU 不可用，已降级 CPU
- ● 灰色 = CPU 模式

**实现位置**: `app/ui/widgets/compact_toolbar.py`（重构现有工具栏）

## 动画与过渡

### 动画规范

| 动画 | 时长 | 缓动函数 | 说明 |
|------|------|----------|------|
| 面板折叠/展开 | 300ms | ease-in-out | 宽度变化 |
| 面板滑入/滑出 | 250ms | cubic-bezier(0.4, 0, 0.2, 1) | 从右侧滑入 |
| 模式切换 | 200ms | ease-out | 淡入淡出 |
| 工具栏展开 | 200ms | ease-out | 高度变化 |
| Toast 出现 | 150ms | ease-out | 从底部滑入 |
| Toast 消失 | 200ms | ease-in | 淡出 |
| 加载骨架屏 | 800ms | linear | 脉冲动画（循环） |
| GPU 状态脉冲 | 2000ms | ease-in-out | 呼吸灯效果（循环） |

### 性能考虑

- 所有动画使用 `QPropertyAnimation`
- 动画过程中禁用重绘区域外的更新
- 提供 `Settings > 外观 > 禁用动画` 选项
- 尊重系统 `prefers-reduced-motion` 设置

   - `app/ui/main_window.py`
   - 移除嵌套 splitter
   - 集成 CollapsiblePanel 和 SlidablePanel
